  ## Implementation
  
  ```python
  def is_palindrome(s: str) -> bool:
      """
      Check if a string is a palindrome.
      
      - Case-insensitive comparison
      - Ignores non-alphanumeric characters
      - Empty string and single characters return True
      
      Args:
          s: Input string to check
          
      Returns:
          True if the string is a palindrome, False otherwise
          
      Examples:
          >>> is_palindrome("Racecar")
          True
          >>> is_palindrome("A man, a plan, a canal: Panama")
          True
          >>> is_palindrome("")
          True
      """
      # Filter to alphanumeric only and convert to lowercase
      cleaned = ''.join(c.lower() for c in s if c.isalnum())
      
      # Compare with reversed string
      return cleaned == cleaned[::-1]
  ```
  
  **Design decisions:**
  - Case-insensitive: `"Racecar"` → `True`
  - Ignores punctuation/spaces: `"A man, a plan..."` → `True`
  - Empty string → `True` (trivially palindrome)
  - Single char → `True`
  
  Ready for review and testing!
